# kakao-bomb 💣

카카오톡(macOS)에서 장전해 두면 **다음에 보낸 내 메시지를 N초 뒤 자동으로 "모두에게서 삭제"** 해주는 메뉴바 앱.

- 채팅창이 앞에 오면 창 옆에 트레이 `[💣 자폭] [−] 0.5초 [+]` 가 자동으로 붙음
- 💣 자폭 또는 **⌃⌥D** → 그 채팅창 장전 (🔥). 한 번 쓰면 자동 해제
- 삭제 지연: 트레이 −/+ (0.1초 단위, 0~10초) 또는 메뉴바 💣 > 삭제 지연. 재실행해도 유지
- 갠톡/단톡 모두 동작 확인 (텍스트 메시지 기준)

## 빌드 / 실행 (macOS)

```sh
swiftc -O -swift-version 5 main.swift -o kakao-bomb
./kakao-bomb            # 메뉴바에 💣
./kakao-bomb --debug    # 삭제 과정 로그 (stderr)
./kakao-bomb --check    # 삭제 없이 각 채팅창 마지막 말풍선 판정만 출력
```

손쉬운 사용 권한 필요 (시스템 설정 > 개인정보 보호 및 보안 > 손쉬운 사용). 터미널에서 실행하면 터미널 권한을 씀.

## 한계

- N초 사이에 상대 폰으로 푸시 알림(미리보기)이 이미 갔을 수 있음
- 상대 채팅방엔 "삭제된 메시지입니다" 흔적이 남음
- 모두에게서 삭제는 카톡 정책상 보낸 지 5분 이내만 가능
- 이모티콘/사진은 말풍선 구조가 달라 감지 안 될 수 있음

## 동작 원리

전부 Accessibility(AX) API로 카톡 UI를 읽고 조작함. 마우스/키보드 입력은 안 씀.

1. **채팅창 구분**: 창 > `AXScrollArea` > `AXTable` 이 있고 제목이 "카카오톡"(메인 창)이 아닌 창
2. **메시지 = 테이블 행**: `AXRow` > `AXCell` > [`AXStaticText`(시간/읽음 수), `AXImage`(말풍선 배경), `AXTextArea`(본문, `AXShowMenu` 지원)]
3. **내 메시지 판정**: 말풍선이 오른쪽 정렬 (테이블 오른쪽 여백 < 왼쪽 여백), `프로필` 버튼 없음
4. **전송 감지**: 장전 시점 행 수/마지막 행을 기준으로, 행 수가 늘고 + 마지막 말풍선이 바뀌고 + 내 것이고 + 화면에 보일 때. 50ms 폴링
5. **삭제**: 말풍선 `AXTextArea`에 `AXShowMenu` → 컨텍스트 메뉴(NSMenu, 대상 요소의 자식으로 붙음)에서 identifier `deleteToAllMessage:` 항목(제목 "모두에게서 삭제")을 `AXPress` → 확인창 뜨면 "삭제"/"확인"
   - "나에게서만 삭제"(`deleteToMeMessage:`)는 절대 안 누름

### 삽질 기록 (포팅할 때 같은 함정 주의)

- **감지 시점에 잡은 UI 요소를 나중에 쓰면 안 됨.** 카톡이 전송 완료 후 행을 다시 그려서 참조가 죽음 → 삭제 직전에 다시 찾아야 함
- **행 번호도 믿으면 안 됨 (단톡).** 감지 후 행이 밀림 → 감지 행 5칸 앞 ~ 끝까지 훑어서 *내용이 같은 내 말풍선 중 가장 최근 것*을 찾음
- 컨텍스트 메뉴에 "삭제" 하위 메뉴 같은 건 없음. "모두에게서 삭제"가 바로 있음
- 마우스 우클릭 방식은 좌표/타이밍 변수가 많아서 버림

## Windows 포팅 노트

Windows 카톡은 완전히 다른 프로그램(Win32)이라 이 코드는 그대로 못 씀. 로직(4~5번 + 삽질 기록)만 가져가면 됨. **아래는 검증 안 된 출발점.**

- 먼저 [Accessibility Insights](https://accessibilityinsights.io/) 나 `inspect.exe`(Windows SDK)로 카톡 채팅창 구조부터 볼 것
  - 메시지 목록이 UI Automation에 행/텍스트로 노출되는지가 관건. 커스텀 컨트롤이라 안 보일 수 있음
  - 입력창은 보통 `RICHEDIT50W` 클래스
- 메시지 목록이 UIA로 안 읽히면 전송 감지는 입력창 기준으로: 장전 상태에서 입력창 텍스트가 비어 있지 않다가 Enter 후 비워지면 "보냄"
- 삭제: 마지막 내 말풍선 컨텍스트 메뉴 → "모두에게서 삭제". 메뉴가 표준 Win32 팝업(`#32768`)이면 UIA `MenuItem`으로 이름 찾아 `Invoke` 가능
- 언어 후보: Python + `pywinauto`/`uiautomation` (+ PyInstaller로 exe), 또는 C# + `System.Windows.Automation`
- 트레이 UI: 채팅창 위치 따라다니는 작은 topmost 창 (`WS_EX_TOOLWINDOW | WS_EX_NOACTIVATE`로 포커스 안 뺏게)
